01.c – Hello World
Simple program to print Hello World.

02.c – Integer Output
Demonstrates how to declare and print an integer variable using %d.

03.c – Variable Assignment
Shows how one integer variable can be assigned to another.

04.c – Data Types and Sizes
Demonstrates various data types (int, double, float, char) and prints their sizes using sizeof().

05.c – Single User Input
Takes input from the user for:

Integer

Double

Character
Shows how to use scanf with %d, %lf, and %c.

06.c – Multiple User Inputs
Takes two inputs (a double and a char) in a single scanf call and prints them.

07.c – Simple Calculator
Performs and displays:

Addition

Subtraction

Multiplication

Division
On two double numbers provided by the user.
